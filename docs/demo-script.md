# Demo script

## 1. The problem (30s)
"Three teams, three agents, nobody can say what runs or whether it works. LangSmith gives the instruments. This is the operating procedure an organization runs on them."

## 2. Admin: what the org owns (45s)
Open Admin. Templates grouped by workflow and agent; the tool catalog with risk, scope, and which teams; two processes drawn as pipelines; users and roles. "The platform team owns this directory. Nobody else edits it."

## 3. Ana creates a claims agent (2 min)
Sign in as Ana (claims analyst, builder). Create: pick Claims processing, a workflow with four steps and one pause. Configure: the coverage rules in plain language, the $2,500 limit, tools filtered to operations. Add one example claim. Review: policy ok, the regulated process drawn. Create + run gate. Open the agent.

## 4. Try it (45s)
Run a $3,100 theft claim. It pauses on recording the referral; approve it; the summary cites the auto-approval limit.

## 5. Promotion through the process (1 min)
Request promotion: gates run, dev to staging. Request again: pending on two approvals. Sign in as Omar (ops lead): the inbox shows the evidence; approve. Sign in as Priya (platform): approve. The agent is in production; Versions shows the ledger.

## 6. Policy says no (30s)
Sign in as Rae (research). Try the claims template: the review step refuses with the exact rules.

## 7. Limits (20s)
Open docs/tradeoffs-and-limits.md. Roles trust a header; files not a database; stand-ins for the Gateway and Engine.
